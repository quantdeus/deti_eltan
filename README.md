# Дети Эльтан: Пепел Второго Дома

> **Статус репозитория: основной канонический репозиторий «Детей Эльтана».**
> Этот код и его исходная игровая база сохраняются как основа проекта. Поверх неё целевыми содержательными изменениями считаются прежде всего **Келлер / Глубокий гипер** и **Smart Diplomacy**; остальное унаследованное содержимое не переписывается без отдельной задачи.
>
> **Godot / Android:** APK — только лёгкий launcher/bootstrap. Файлы игры, модов и крупные пакеты данных **не встраиваются в APK**: launcher получает манифесты, отдельно скачивает/обновляет нужные игровые и модовые слои, проверяет версии/целостность и затем запускает установленный контент. Цель — маленький обновляемый APK вместо монолитной 10+ ГБ сборки.
>
> **SR Mods Launcher** остаётся совместимым общим слоем установки/профилей для КР2, а `ChildrenOfEltanLauncher.exe` — узким Windows native-bridge там, где нужны существующие DLL-хуки. Они не заменяют этот репозиторий как источник канонической игровой реализации.


Мод для Space Rangers HD: A War Apart. Влетите в чёрную дыру с «Якорем Двух
Домов» в трюме — и окажетесь во Втором Доме, втором рукаве Галактики, где у
систем и созвездий свои имена, а Союз Детей Эльтан встречает рейнджера приказом
Совета четырёх взять его живым.

Капитан переносится целиком: деньги, опыт, навыки, дата, трюм и снаряжение —
каждый предмет возвращается в тот же слот, с тем же износом, акрином и
микромодулем.

## Как это устроено

Второй рукав — не «вторая галактика» внутри одной партии: движок такого не
умеет, и попытки заставить его кончились ничем (см. `docs/`). Это отдельный мир
в отдельном файле сохранения, а переход — управляемая загрузка, при которой
состояние капитана переносится через нативный слой.

Мир Второго Дома мод создаёт сам, из галактики самого игрока, при первом
использовании Якоря. Это не удобство, а необходимость: сохранение несёт в себе
скрипты и состояние того набора модов, при котором оно сделано, поэтому заранее
заготовленный файл ломает игру у всех, у кого набор другой.

Нативная часть — DLL, которую в текущем резервном прототипе внедряет
`ChildrenOfEltanLauncher.exe`. Она умеет работать на двух движках: стоковом из
Steam и патченном из сборки Universe. Адреса под Universe выведены
дифференциальным сопоставлением двух исполняемых файлов
(`tools/derive_addresses.py`), движок определяется по размеру секции кода, а
каждая заплатка перед записью сверяет байтовую сигнатуру и отказывается
ставиться, если та не совпала.

Этот launcher больше не считается общей точкой входа для модов КР2. Его роль —
узкий **fallback/native-bridge** для специфичных хуков «Детей Эльтана». Общие
задачи сборок, профилей, установки, обновлений и `ModCFG` должны переноситься в
SR Mods Launcher, а собственный launcher сохраняется только пока без него нельзя
воспроизвести native-переход.

## Установка

**Android / Godot:** устанавливается компактный APK-лаунчер; после запуска он
отдельно получает игровые файлы, модовые пакеты и обновления по манифестам.
Крупный контент не должен становиться частью APK.

**Windows / текущий КР2-контур:** пакет/профиль мода может устанавливаться и
обслуживаться через SR Mods Launcher.

Для текущего резервного native-прототипа пока требуется:

1. Положить папку `ChildrenOfEltan` в `Mods` игры.
2. Включить мод в игровом списке модификаций.
3. Для функций Второго Дома, которым нужна DLL-инъекция, запустить
   `ChildrenOfEltanLauncher.exe`. Без native-bridge мод загрузится, но переход
   работать не будет.

Это временное техническое исключение, а не новый стандарт установки модов КР2.

Сборка Universe не обязательна. С установленным `ShuKlissan` во Втором Доме
заводятся клисанские гнёзда; без него рукав просто обходится без них.

## Что работает

- переход в Второй Дом через чёрную дыру;
- перенос денег, опыта, навыков, даты, трюма и снаряжения по слотам;
- собственные названия систем, созвездий, планет и станций;
- доминаторов и пиратского клана во втором рукаве нет;
- клисане, если установлен `ShuKlissan` — редкие, с потолком численности.

## Что ещё не работает

- возврат в первый рукав: загрузка встаёт под конец;
- гипер-переходы после прыжка могут зациклиться.

Обе неполадки, судя по логам, имеют общую причину — флаг «эта загрузка наша»,
который остаётся поднятым дольше, чем следует.

## Сборка из исходников

```
pwsh -File tools/install-game-smoke.ps1 -GameRoot "путь\к\игре" -Install
```

Нужны PowerShell 7, Python 3 и `references/tools/` (RScript, BlockParEditor,
llvm-mingw) — они не в репозитории.
