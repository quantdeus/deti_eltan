# Canon: Keller and Smart Diplomacy

Дата фиксации: **2026-10-07**

## 1. Источник истины

Основной игровой репозиторий проекта — **`quantdeus/deti_eltan`**.

Правило миграции: текущую унаследованную игровую базу сохранять. Не превращать
перенос концепта в общий rewrite. Без отдельной задачи не менять существующие
миссии, мир, баланс, контент, native-переход и прочие несвязанные системы.

Целевые содержательные надстройки:

1. **Келлер / Глубокий гипер**.
2. **Smart Diplomacy**.

Мобильный Godot/bootstrap ведётся отдельно в ветке `mobile-godot-bootstrap`.

## 2. Keller / Deep Hyper

Келлер — не очередной обычный NPC и не статичный финальный босс.

Канон концепта:

- Келлер — скрытый стратег **Глубокого гипера**.
- Он ведёт долгую войну против Махпелл и связанных с ними угроз.
- За пределами обычного пространства он собирал тайные межпространственные
  связи и союзы, но для войны в нормальном пространстве ему нужна реальная
  армия и политический мост.
- **Дети Эльтан** становятся одним из ключевых элементов этой стратегии.
- На старте соответствующей сюжетной линии Келлер может выступать союзником,
  но союз не является безусловным: он оценивает полезность фракций и игрока.
- Межрасовые противоречия нельзя сглаживать одной универсальной шкалой
  "все друзья".
- При провале общего альянса Келлер может отойти обратно в Глубокий гипер.

Любая реализация должна опираться только на подтверждённые возможности
SRHD/RScript/native-bridge. Не изобретать API ради лора.

## 3. Smart Diplomacy

Smart Diplomacy — постоянная система отношений, а не набор разовых диалогов.

### Базовая модель

- отношения: **-100..100**;
- vertical slice:
  - trade: **+5**;
  - aid: **+10**;
  - threat: **-15**;
  - attack: **-40**;
- состояние сохраняется и восстанавливается с партией;
- одинаковое состояние + одинаковое действие дают одинаковый результат.

### Анти-фарм и боевые последствия

- первый успешный buy/sell с фракцией за ход может дать **+1**;
- повторные сделки в том же ходу не фармят репутацию;
- первый подтверждённый удар по мирной/фракционной цели даёт **-40**;
- повторные попадания по той же цели не должны бесконечно стакать штраф;
- пиратские цели могут использовать отдельные правила.

### Alliance Grid

Дипломатия учитывает не только "игрок ↔ фракция", но и сетку отношений между
участниками союза.

Решение может зависеть от:

- профиля расы/фракции;
- текущих союзов и конфликтов;
- предыдущей помощи или агрессии;
- разведданных;
- блефа;
- подкупа;
- поведения игрока в войне;
- отношения к Келлеру и его стратегии.

Разные стороны имеют разные психологические профили; переговоры нельзя сводить
к одному универсальному шаблону.

### Discord Index

Над Alliance Grid существует **Discord Index** — агрегированная мера внутреннего
развала союза.

Он растёт от несовместимых решений, предательства, провалов переговоров и
эскалации между союзниками. Высокий Discord имеет реальные последствия:
альянс теряет согласованность, может распасться, а Келлер получает основание
прекратить проект союза и уйти обратно в Глубокий гипер.

Числовые пороги Discord не фиксировать догадкой: определить их отдельной
задачей и покрыть тестами.
