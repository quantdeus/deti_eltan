# Canon: Godot Android launcher, Keller and Smart Diplomacy

Дата фиксации: **2026-10-07**

## 1. Источник истины

Основной игровой репозиторий проекта — **`quantdeus/deti_eltan`**.

Правило миграции: текущую унаследованную игровую базу сохранять. Не превращать
перенос концепта в общий rewrite. Без отдельной задачи не менять существующие
миссии, мир, баланс, контент, native-переход и прочие несвязанные системы.

Целевые содержательные надстройки, которые нужно перенести в эту базу:

1. **Келлер / Глубокий гипер**.
2. **Smart Diplomacy**.

## 2. Godot / Android: APK = launcher, не игра

Godot-сборка для Android должна быть компактным launcher/bootstrap APK.

В APK допустимы:

- UI лаунчера;
- логика bootstrap/update;
- клиент манифеста;
- менеджер локальных профилей/версий;
- скачивание с возобновлением;
- проверка целостности и версий;
- запуск уже установленного контента;
- минимальные служебные ресурсы самого launcher.

В APK **не должны** встраиваться:

- полный набор файлов игры;
- все моды;
- многогигабайтные архивы;
- контент, который можно получить как отдельный versioned package.

Ожидаемый цикл:

`APK -> manifest -> resolve packages -> download/update -> verify -> activate profile -> launch`.

Игровой слой и модовый слой должны обновляться независимо. Обновление launcher
не должно требовать повторной упаковки всей игры, а обновление мода — выпуска
нового многогигабайтного APK.

### Совместимость существующих launcher-ов

- `ChildrenOfEltanLauncher.exe` сохраняется как узкий Windows native-bridge для
  уже существующих DLL-хуков и перехода между рукавами.
- SR Mods Launcher может оставаться общим слоем установки, профилей, `ModCFG`
  и совместимости КР2.
- Ни один из них не отменяет правило, что каноническая игровая реализация живёт
  в `deti_eltan`.

## 3. Keller / Deep Hyper

Келлер — не очередной обычный NPC и не статичный финальный босс.

Канон концепта:

- Келлер — скрытый стратег **Глубокого гипера**.
- Он ведёт долгую войну против Махпелл и связанных с ними угроз.
- За пределами обычного пространства он собирал тайные межпространственные
  связи и союзы, но для войны в нормальном пространстве ему нужна реальная
  армия и политический мост.
- **Дети Эльтан** становятся одним из ключевых элементов этой стратегии.
- На старте соответствующей сюжетной линии Келлер может выступать союзником,
  но союз не является безусловным: он оценивает полезность фракций и игрока.
- Келлер враждебно относится к части коалиционных сил; межрасовые противоречия
  нельзя сглаживать одной универсальной шкалой "все друзья".
- При провале общего альянса Келлер не обязан оставаться в обычном пространстве:
  сюжетный выход — отход обратно в Глубокий гипер.

Любая реализация должна опираться только на реально подтверждённые возможности
SRHD/RScript/native-bridge. Не изобретать несуществующий API ради лора.

## 4. Smart Diplomacy

Smart Diplomacy — постоянная система отношений, а не набор разовых диалогов.

### Базовая модель

- отношения хранятся в диапазоне **-100..100**;
- базовые детерминированные действия vertical slice:
  - trade: **+5**;
  - aid: **+10**;
  - threat: **-15**;
  - attack: **-40**;
- состояние сохраняется и восстанавливается с партией;
- одинаковое состояние + одинаковое действие должны давать одинаковый результат.

### Анти-фарм и боевые последствия

- первый успешный buy/sell с фракцией за ход может дать малый бонус отношений
  (**+1**); повторные сделки в том же ходу не фармят репутацию;
- первый подтверждённый удар по мирному/фракционному кораблю даёт канонический
  штраф **-40**;
- повторные попадания по той же цели не должны бесконечно стакать один и тот же
  штраф;
- пиратские цели не обязаны использовать то же правило мирной агрессии.

### Alliance Grid

Дипломатия должна учитывать не только "игрок ↔ фракция", но и реальную сетку
отношений между участниками союза.

Решение может зависеть от:

- профиля конкретной расы/фракции;
- текущих союзов и конфликтов;
- предыдущей помощи или агрессии;
- разведданных;
- блефа;
- подкупа;
- поведения игрока в войне;
- отношения к Келлеру и его стратегии.

Разные стороны имеют разные психологические профили. В частности, гибриды могут
считать себя превосходящими другие расы, а Теневые флоты — опасаться
"поверхностных" цивилизаций. Нельзя сводить все переговоры к одному шаблону.

### Discord Index

Над Alliance Grid существует **Discord Index** — агрегированная мера внутреннего
развала союза.

Он растёт от несовместимых решений, предательства, провалов переговоров и
эскалации между союзниками. Высокий Discord должен иметь реальные последствия:
альянс теряет согласованность, может распасться, а Келлер получает основание
прекратить проект союза и уйти обратно в Глубокий гипер.

Числовые пороги Discord не фиксировать догадкой: сначала определить их в
отдельной задаче и покрыть тестами.

## 5. Правило для агентов

При любой работе по этому канону:

1. Сначала прочитать этот документ и `AGENTS.md`.
2. Делать минимальный локальный diff.
3. Не переписывать несвязанные системы "заодно".
4. Keller/Smart Diplomacy добавлять поверх существующей базы через ясные модули,
   persisted state и тестируемые переходы.
5. Godot APK держать маленьким; крупный контент — только внешними пакетами.
6. Не заявлять игровой runtime как рабочий без соответствующего smoke/evidence.
